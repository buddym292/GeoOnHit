GeoOnHit



A Hollow Knight mod that drops Geo coins when your nail hits an enemy, with drop amounts scaling by nail level and actual damage dealt — similar to breaking a Geo rock or an enemy dropping Geo on death.



Features



· Spawns Geo coins at the enemy's position when nail slashes, Great Slash, Dash Slash, or Cyclone Slash hit an enemy.

· Drop count is calculated from the current nail level and the actual damage dealt by that hit.

· Per-enemy cooldown prevents multi-hit attacks (Cyclone Slash, repeated pogo) from spawning huge amounts of coins in a single instant.

· Optional: whether Grubberfly's Elegy beams (NailBeam) also trigger drops.

· Configurable min/max drop per hit to avoid stutter from extreme crit or damage-stacking builds.



Installation



1\. Make sure the Modding API for Hollow Knight is installed.

2\. Place GeoOnHit.dll into the game's Mods folder:



&#x20;  ...\\Hollow Knight\\hollow\_knight\_Data\\Managed\\Mods\\



3\. Launch the game. The mod loads automatically. A global settings file is generated on first run.

Settings are handled by IGlobalSettings. Changes take effect after restarting the game.

Drop Calculation



On each valid hit:



drop = round( baseGeo × actualDamage / nailBaseDamage )

drop = Clamp(drop, MinGeoPerHit, MaxGeoPerHit)



· baseGeo is determined by the current nail level inside CalculateGeoAmount().

· actualDamage is hitInstance.DamageDealt, which already includes Fragile/Unbreakable Strength, Fury of the Fallen, nail art multipliers, and any other damage bonuses.

· nailBaseDamage is PlayerData.instance.nailDamage, i.e. 5 / 9 / 13 / 17 / 21.

Cooldown



· The same HealthManager instance only triggers a drop once every 0.3 seconds.

· Cooldowns are tracked per enemy instance, so different enemies don't affect each other.

· Stale entries are cleaned up every 5 seconds to prevent the dictionary from growing indefinitely.



Notes



· Does not work in Godhome: Godhome is designed to not produce Geo. The Geo Small prefab may not be present in the object pool, or spawned Geo may be removed by scene logic. This is Godhome's intended behavior, not a broken hook.

· Breakables also drop Geo: Hidden walls, vines, etc. have HealthManager components and will also trigger drops when hit by the nail. If you want to exclude them, add a check in HealthManager\_TakeDamage.

· Multi-hit attacks: Each hit from Cyclone Slash or repeated pogo is still limited by the per-enemy cooldown, so only one drop occurs per 0.3 seconds.

· Cap: MaxGeoPerHit clamps drops from extreme damage, preventing dozens of coins from spawning at once and causing stutter.

GeoOnHit



一个《空洞骑士》模组：骨钉命中敌人时掉落吉欧硬币，掉落数量随骨钉等级和实际伤害成长，效果类似敌人死亡时掉钱。



功能



· 骨钉平A、蓄力斩、冲刺斩、旋风斩命中敌人时，在敌人位置生成吉欧硬币。

· 掉落数量基于当前骨钉等级和本次实际伤害计算。

· 每个敌人有独立冷却，防止旋风斩、连续下劈等多段攻击在瞬间刷出大量硬币。

· 可选：蜕变挽歌的剑气（NailBeam）是否也触发掉落。

· 可设置单次掉落的上下限，避免暴击或极端配置导致硬币过多、卡顿。

冷却机制



· 同一个 HealthManager 实例在 0.3 秒内只会触发一次掉落。

· 冷却按敌人实例独立计算，不同敌人互不影响。

· 过期条目每 5 秒清理一次，避免字典无限增长。



注意事项



· 神居不生效：神居场景本身不产出吉欧，对象池中可能没有 Geo Small 预制体，或生成的吉欧会被场景逻辑清除。这是神居的设定，不是模组 Hook 失效。

· 可破坏物也会掉：隐藏墙、藤蔓等也有 HealthManager，骨钉打上去同样会触发掉落。如果不想这样，可以在 HealthManager\_TakeDamage 里加判断排除。

· 多段攻击：旋风斩、连续下劈的每段命中都受同一敌人冷却限制，0.3 秒内只掉一次。

· 上限：MaxGeoPerHit 会截断极端伤害下的掉落，防止一次飞出几十枚硬币导致卡顿。
